Cross-type analysis reports two distinct findings — short-range colocalization (10–20 µm) and co-infiltration (20–50 µm) — each as attraction or segregation on the calibrated primary null. OASIS uses the 75 µm intensity-reweighted primary when its architecture check passes; if the tissue is fine/dense it switches to the dense morphology-conditioned null, and if one marker is sparse it runs on the all-cell support null (flagged UNDERPOWERED) so segregation is still reported. This is a population-level serial-section statistic; it does not imply single-cell co-expression, which requires multiplex imaging on the same section.

Train a classifier BETA

Fit positivity to this cohort's own labelled cells

When this is worth doing. Measured against DeepLIIF's immunofluorescence-derived labels (6,663 cells, 149 images): on clean, consistently stained material a trained classifier does not beat a well-chosen fixed cutoff — held-out F1 0.771 against 0.781, and the fixed cutoff is already within 0.012 of the best any single threshold can do. It wins when staining varies across the cohort: under simulated batch-to-batch drift the classifier holds at 0.765 while every fixed cutoff collapses (0.20 OD falls to 0.484). The crossover is around 0.08 OD of per-slide drift.
So: if your slides were stained in one run and look consistent, the fixed cutoff plus the review step is the better tool and costs no labelling. Reach for this when slides came from different runs, lots or scanners — and typically once you have 20+ slides, below which you can still check every slide by eye.

Membranous markers — works only on well-stained tissue

Beta — membranous markers only, and only on well-stained tissue. On faintly stained slides the limit is staining contrast, not the cutoff: the positive and negative populations overlap in the ring signal, so no threshold separates them and calibration cannot rescue the image. Expect the classifier to abstain there rather than produce a confident wrong answer. Judge whether a slide qualifies using the DAB signal view while labelling.
Fit membrane cutoffs to your own slides
DAB staining isn't quantitative — "how much brown = positive" differs by antibody, protocol and scanner, so cutoffs from another dataset won't transfer.
