Nuclear segmentation

Every nucleus in the image is outlined by InstanSeg, a trained instance-segmentation model that runs in-process. The model is fixed and has nothing to tune. Nothing on this step decides which cells are positive.

Stain normalization — per-image white balance
Rescales each colour channel so this slide's own background maps to white, correcting tone and uneven illumination before the model sees the image. It does not rescale the DAB signal, so it cannot move positivity by itself. Worth using when slides vary in tone or are unevenly lit.
Normalize before segmenting
Segmentation is cached. Re-running the same images at the same pixel size reuses the result instead of segmenting again.

Marker
Named in the outputs and used to pick sensible starting cutoffs.
Compartment — where the stain is measured
DAB is measured either inside the segmented nucleus, or in a ring of cytoplasm just outside it.
Membranous — measure the cytoplasmic ring
For markers on the cell surface, such as CD8 and TIM-3. A ring is grown outward from each nucleus and clipped against its neighbours, then scored on how much of it is stained rather than on how brown it is on average — a faint but complete rim is a positive cell, and an average cannot tell that from diffuse background.
Needs a trained membrane classifier, and well-stained tissue.
Label cells on 3 slides or more in the Classifier tab. There is no hand-set membranous cutoff: no single ring number beats a plain nuclear cutoff, so the choice is a fitted classifier or the nuclear cutoff, not a slider.
Where the stain is faint nothing separates positive from negative — turn this off and use the nuclear cutoff, which does nearly as well on good tissue and costs no labelling. A classifier also does this per image: a slide outside its training range is handed back to the cutoff and named in the results. Evidence: research/ihc.md § 11.7.
Positivity rule
A fixed optical-density cutoff is the default and is usually the right answer: one number for the cohort, adjustable per image against that image's own histogram after segmentation. A trained classifier is worth its labelling cost only when staining varies so much across the cohort that no single cutoff fits.
A membranous marker is scored by a trained classifier — that is the only option here. Only classifiers fitted on the ring are listed; a nuclear one reads measurements a ring does not have.
Optical density (OD) cutoff — 0.20
Optical density is how strongly a pixel absorbs light once the stain has been separated into its haematoxylin and DAB components — higher means more brown. A cell is positive when the DAB optical density inside its nucleus is above this value.In membranous mode this is the fallback: it calls the cells of any slide the classifier refuses, on nuclear DAB. It scores nothing on a slide the classifier accepts.
A starting value for the whole cohort. You will see every image's histogram before anything is written.

Microscope & scanner
Scale bar

What the burned-in bar represents

OASIS measures the drawn bar in an image's _scale sibling and divides this length by it to get µm/px. That makes this the single most load-bearing number in the app: every distance the spatial statistic reports — the 10–20 µm and 20–50 µm bands, the 75 µm architecture bandwidth, the certified cell error — is derived from it. It is a property of the microscope's export preset, so it is set once per cohort here rather than per image.

Bar length (µm)
Read the label printed beside the bar on your slides and enter it here. Almost every export draws 100 µm.
Cohort pixel size
The µm/px for a cohort acquired on one scope at one magnification. Set it once here and every run can take it without retyping. It is the weakest of the three sources and is used only when nothing better is available.
Which pixel size wins
1. Per-image exception Set by hand for one image in the Quant pixel-size step. Always wins.
2. Matched scale bar Measured from that image's own 100 µm bar. Best evidence — scale varies between images even at one magnification.
3. This run's value A single scale bar, or a number typed on the Quant step.
4. Cohort pixel size The value above, when a run explicitly asks for it. Never applied silently.
A run is blocked rather than guessing: if none of these is available, nothing is measured.

Train a classifier

Fit positivity to this cohort's own labelled cells

What you are about to build

A rule that decides positive from negative, fitted on cells you label yourself and scored on slides it has never seen. It replaces the fixed cutoff for every image it accepts.

When this is worth the labelling
Measured against DeepLIIF's immunofluorescence-derived labels (6,663 cells, 149 images): on clean, consistently stained material a trained classifier does not beat a well-chosen fixed cutoff — held-out F1 0.771 against 0.781, and the fixed cutoff is already within 0.012 of the best any single threshold can do. It wins when staining varies across the cohort: under simulated batch-to-batch drift the classifier holds at 0.765 while every fixed cutoff collapses (0.20 OD falls to 0.484). The crossover is about 0.08 OD of per-slide drift.
If your slides were stained in one run and look consistent, the fixed cutoff plus the review step is the better tool and costs no labelling. Reach for this when slides came from different runs, lots or scanners — and typically once you have 20+ slides, below which you can still check every slide by eye. A membranous marker is the exception: it requires one.
